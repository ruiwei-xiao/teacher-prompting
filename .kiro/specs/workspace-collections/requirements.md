# Requirements Document

## Project Description (Input)

On top of the educator Workspaces delivered by `educator-workspaces` (create/invite/roles, bot placement, building permissions, lightweight activity), add Playlab-like Collections plus richer cross-workspace activity/insights and, when needed, an Organization layer. After phases 1–2, there is still no way to package and distribute a curated set of bots (e.g. a course starter pack), and facilitators lack deeper aggregates across workspaces. This phase-3 spec covers Collections (curated multi-bot distribution), fuller insights, and optional Organization introduction. Do not proceed immediately into design/tasks/implementation; refine and approve requirements, then park the spec until `educator-workspaces` is implemented and validated and phase-3 need is clear. Dependency: `educator-workspaces`.
