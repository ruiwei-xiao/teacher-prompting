# Product Overview

Teacher Prompting is a pedagogical-agent authoring and delivery platform. It helps educators turn learning goals, learner context, teaching approaches, and course materials into purpose-built AI tutoring bots. The workflow emphasizes deliberate prompt design, simulated learner testing, and controlled publishing before a bot reaches students.

The primary creators are teachers and other educator-builders with varied prompting experience. Students use the published tutoring experiences, while peer educators can inspect, reuse, and adapt shared projects.

## Core Capabilities

- **Tutor creation and management**: Create bots for distinct courses, learner populations, or teaching goals and configure the model and project metadata for each one.
- **Pedagogical prompt authoring**: Build a final system prompt from learning objectives, learner profiles, teaching strategies, reference materials, reusable templates, and AI-assisted feedback.
- **Behavior evaluation**: Exercise prompts against simulated student profiles and edge cases, inspect generated dialogues, revise the prompt, and use test completion as a publishing gate.
- **Student learning experiences**: Publish standalone tutoring interfaces that support conversational learning, rich content, attachments, and domain-appropriate interactive or visual aids where available.
- **Educator sharing and reuse**: Keep student-facing chatbot links distinct from project-sharing links, discover public projects, and duplicate useful work with attribution.

## Target Use Cases

- An educator designs a tutor around a specific learning objective, learner group, and pedagogical approach.
- An educator tests expected and challenging learner behaviors, then iterates until the tutor is ready to publish.
- A student opens a published link and learns through a focused, multimodal tutoring conversation.
- An educator shares a project for peer review or adapts a community project for another course or teaching goal.

## Value Proposition

The product lowers the barrier to creating purposeful AI learning experiences without treating a prompt as a one-off text artifact. It joins authoring, pedagogical scaffolding, simulated evaluation, student delivery, and educator reuse in one workflow, helping teachers make tutoring behavior visible and improvable before deployment.
